# Archived paper materials

This folder contains an earlier, exploratory manuscript on geospatial site selection for underground hydrogen storage.

That work is not the current research direction of this repository. The project now focuses on hydrogen dissolution, retention and loss in water-bearing geological formations, especially the roles of brine chemistry, pore confinement and mineral-fluid interactions.

The earlier manuscript and its submission notes are retained for historical reference. They are not an approved or current submission package. Do not use the old submission instructions, abstract, site rankings, PINN claims or proposed journal targets as evidence of validated results or as a description of the current project.
