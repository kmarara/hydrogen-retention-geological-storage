# Canonical observation schema for the hydrogen–brine IFT benchmark

**Status:** schema specification; no observations have been added or certified.  
**Applies to:** the frozen benchmark table assembled after source acquisition and provenance review.

## Design principles

1. One row represents one reported experimental IFT observation or one explicitly labelled non-experimental record.
2. Preserve source-reported values and units. Never overwrite them with converted values.
3. Keep source study, original publication, data repository record and extraction location traceable.
4. Distinguish a direct measurement from a table transcription, digitisation, calculation, simulation or representative point.
5. Preserve fluid chemistry and measurement method as categorical metadata; do not encode unlike systems as one generic salinity variable.
6. Derived quantities must record their formula, inputs, unit conversion and software/version.

## Required row-level fields

| Field | Type / unit | Meaning and rule |
|---|---|---|
| observation_id | string | Stable unique ID; never reuse after deletion. |
| source_study_id | string | Canonical ID for the underlying experimental study, not merely the paper citing it. |
| citing_publication_doi | string | DOI of the publication from which the row was extracted. |
| original_study_doi | string | DOI of the original experiment, if different and known. |
| source_location | string | Exact page, table, figure, equation, supplementary filename/sheet/cell or paragraph. |
| provenance_status | controlled string | One of the statuses below. |
| benchmark_eligible_primary | boolean | True only after documented source verification and eligibility review. |
| pressure_value_original | number | Pressure exactly as reported. |
| pressure_unit_original | string | Original pressure unit. |
| pressure_MPa | number | Normalised pressure in MPa, calculated without discarding original value/unit. |
| temperature_value_original | number | Temperature exactly as reported. |
| temperature_unit_original | string | Original temperature unit. |
| temperature_K | number | Normalised temperature in K. |
| IFT_value_original | number | IFT exactly as reported. |
| IFT_unit_original | string | Original IFT unit. |
| IFT_mN_m | number | Normalised IFT in mN/m. |
| gas_composition_original | string | Source-reported gas identity/composition. |
| gas_H2_mole_fraction | number | H2 mole fraction only where reported or explicitly derivable. |
| gas_CO2_mole_fraction | number | CO2 mole fraction only where reported or explicitly derivable. |
| gas_CH4_mole_fraction | number | CH4 mole fraction only where reported or explicitly derivable. |
| gas_phase_y_CO2_non_aqueous | number, optional | State-dependent non-aqueous-phase CO2 mole fraction; never substitute for feed-gas composition. Used for Chow et al. (2018) ternary observations. |
| electrolyte_identity | string | Explicit salt identity; e.g. NaCl, mixed NaCl–KCl, multicomponent. |
| electrolyte_composition_original | string | Original composition and basis, including component proportions where reported. |
| concentration_value_original | number | Original concentration value. |
| concentration_basis_original | string | e.g. mol/kg solvent, mol/L, mass fraction, ppm; never infer silently. |
| concentration_mol_kg | number | Normalised molality only when validly derivable. |
| measurement_method | string | Exact method label from source, e.g. pendant drop. |
| measurement_uncertainty_original | string | Reported uncertainty and its stated meaning, or null. |
| extraction_method | controlled string | Direct table extraction, supplementary data, figure digitisation, etc. |
| conversion_notes | string | Formula, assumptions, and source for each unit/basis conversion. |
| duplicate_group_id | string | Shared ID for suspected or confirmed duplicate/overlapping observations; otherwise null. |
| reviewer_status | controlled string | pending, verified, rejected, or needs_clarification. |

## Controlled provenance statuses

- `direct_measurement`: the original experimental record is directly accessible and the row is traceable.
- `table_extracted`: transcribed from a publication table or supplementary table.
- `figure_digitised`: extracted from a plotted figure; retain digitisation method and uncertainty.
- `correlation_generated`: generated by an empirical equation; never treat as an experimental observation.
- `simulation`: produced by molecular dynamics or another simulation workflow.
- `derived_conversion`: calculated from other reported values; formula and inputs required.
- `representative_unverified`: illustrative/representative point without verified measurement lineage.
- `unknown`: provenance not established.

## Eligibility rules

- Primary experimental benchmark: verified direct measurements and traceable table-extracted measurements, subject to source and independence review.
- Figure-digitised observations: exclude from the primary analysis unless the protocol explicitly permits them; include in a separately reported sensitivity analysis with digitisation uncertainty.
- Correlation-generated, simulation, representative_unverified and unknown records: exclude from the primary experimental benchmark.
- Derived conversions: eligible only when the underlying experimental observation is eligible and the conversion is dimensionally and chemically valid.
- Repeated values are not automatically errors. Resolve them against source coordinates and study lineage.
- If multiple papers reuse the same experiment, retain one canonical observation lineage and flag all duplicate representations before splitting.

## Split-group fields

Create and freeze these group identifiers after source review:
- `publication_group_id`: publication-level grouping for leave-one-publication-out evaluation.
- `experiment_group_id`: underlying experimental campaign/apparatus/data lineage, where identifiable.
- `fluid_system_group_id`: chemistry-defined family with explicit composition rules.
- `measurement_campaign_id`: shared instrument/campaign grouping where reported.

Do not substitute a paper DOI for an experiment identifier when a review or later paper republishes earlier data.

## Validation before model use

A dataset release is not benchmark-ready until:
1. required fields are populated or explicitly marked unknown with a reason;
2. source coordinates and original units are checked;
3. all unit conversions are tested and reproducible;
4. source overlap and duplicate lineage are reviewed;
5. eligibility decisions are recorded;
6. the exact CSV/parquet snapshot is checksummed and versioned;
7. publication and fluid-system split manifests are generated from frozen group IDs.

The combined file is `data/processed/canonical/ift_source_verified_stage1_158_observations.csv` (42 columns; SHA-256 `94fde4ebfcc76ab7a12437079467dcc0e24f2cc98a5966f6802238155a25d89a`).

These are source-level verified candidate observations, **not a released benchmark**. Cross-publication overlap/duplicate review, complete conversion tests, final schema tests, frozen snapshot review and split manifests remain mandatory before model training.
